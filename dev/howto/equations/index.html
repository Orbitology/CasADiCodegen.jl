Write a model as equations

The submodule CasADiCodegen.Models compiles equations among the variables of a model, with derivatives on either side, into the semi-explicit form of the CasADi integrators: differential states x with x' = ode(x, z, p, t) and algebraic states z with 0 = alg(x, z, p, t). SciML and CasADi solvers can then integrate the model.

Write equations with Differential and ~

Load the submodule, make a scalar SX symbol for the time, and take its Differential:

using CasADiCodegen, CasADiCodegen.Models
import SciMLBase
using OrdinaryDiffEqTsit5: Tsit5

t = SX.sym("t")
D = Differential(t)

D(x) is the derivative symbol dx, and D(D(x)) is ddx; for SX.sym("q", 2) the symbols are dq_0 and dq_1. D of an expression applies the chain rule, and System later sets the derivatives of the parameters to 0:

x, v = SX.sym("x"), SX.sym("v")
m, k, c = SX.sym("m"), SX.sym("k"), SX.sym("c")
D(m * x^2 + sin(t))
SX((((sq(x)*dm)+(m*((2.*x)*dx)))+cos(t)))

Write each equation with ~ between two SX expressions or numbers; an equation of two vectors of one size stands for one equation per element. A damped oscillator:

laws = [D(x) ~ v, m * D(v) ~ -k * x - c * v]
2-element Vector{CasADiCodegen.Models.Equation}:
 dx ~ v
 (m*dv) ~ (-((k*x)+(c*v)))

Turn the equations into a System

Give the equations, the time and the parameters to System:

oscillator = System(laws, t; parameters = [m, k, c], name = "oscillator")
System "oscillator" in t with 2 differential states, 0 algebraic states, 3 parameters and 2 observed variables

Every other symbol is a variable, counted once with its derivatives, and the model needs one scalar equation per variable. System throws an ArgumentError when the counts differ, when two symbols share a name, or when elimination leaves an equation without variables.

System solves for the highest derivatives when they enter linearly with a nonsingular coefficient; otherwise they become algebraic states, as in exp(D(x)) ~ x, and need initial values. equations gives the compiled model, unknowns its states, parameters its parameters, and observed the removed variables with their expressions:

equations(oscillator)
2-element Vector{CasADiCodegen.Models.Equation}:
 dx ~ v
 dv ~ (-(((k*x)+(c*v))/m))

In a second-order equation, the derivative below the highest, dx, becomes a state:

newton = [m * D(D(x)) ~ -k * x - c * D(x)]
second_order = System(newton, t; parameters = [m, k, c])
unknowns(second_order)
2-element Vector{SX}:
 SX(x)
 SX(dx)
How `System` orders the states and removes algebraic equations

The states come in the order in which the variables first appear, each followed by its lower derivatives, and then the algebraic states. System also eliminates each algebraic equation that is linear in a variable with a constant or parametric coefficient, such as a ~ b, and keeps the eliminated variable as observed; the other algebraic equations stay, and System differentiates them when needed (index reduction), with the keyword baumgarte_pole for stabilization. The docstring of System lists the steps, and Model a circuit and a pendulum as DAEs applies them.

Solve the model with a SciML solver

Give the initial values and the parameters to SciMLBase.ODEProblem as pairs from a symbol, or its name, to a value; dx is a state here:

u0 = [x => 1.0, :dx => 0.0]
tspan = (0.0, 10.0)
params = [m => 1.0, k => 4.0, c => 0.5]
problem = SciMLBase.ODEProblem(second_order, u0, tspan, params)
solution = SciMLBase.solve(problem, Tsit5())
solution[:x][end], solution[:ddx][end]
(0.05338230813311136, -0.14418704517268782)

A differential state or a parameter without a value makes ODEProblem throw an ArgumentError, and observed variables such as ddx are indexed by name.

A model with algebraic states has a mass matrix and needs a solver such as Rodas5P of OrdinaryDiffEqRosenbrock.jl. An algebraic state without a value starts from 0; give a consistent value, or pass initializealg = BrownFullBasicInit() of OrdinaryDiffEqNonlinearSolve.jl to solve. After index reduction, the initial states must also satisfy the invariants.

Build a CasADi integrator from the model

Dict(sys) returns the dictionary of a CasADi integrator, with "x", "z", "p", "t", "ode" and "alg", without the entries that the model lacks:

F = casadi.integrator("F", "cvodes", Dict(second_order), 0.0, 10.0)
x0 = casadi.DM([1.0, 0.0])
p0 = casadi.DM([1.0, 4.0, 0.5])
result = F(Dict("x0" => x0, "p" => p0))
result["xf"]
DM([0.0534584, -0.138653])

"x0" and "z0" take the states in the order of unknowns, and "p" the parameters in the order of parameters. A model with algebraic states needs a DAE plugin such as "idas".
