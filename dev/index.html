CasADiCodegen.jl: Julia code generation for CasADi functions

CasADiCodegen.jl generates plain Julia code from the functions of CasADi. A model and its derivatives, built with CasADi through its Julia front end CasADiNative.jl, become Julia functions that run without CasADi and accept arrays, static arrays, sparse matrices and ForwardDiff.jl dual numbers.

Features:

  • Functions for the current session with build_function, or a module on disk with generate_julia, each in an out-of-place and an in-place form.
  • Models saved by CasADi from Python, MATLAB or C++, generic Julia code traced into CasADi, and equations with time derivatives compiled by CasADiCodegen.Models.
  • Calls to Julia functions inside a model, with user or automatic derivatives.
  • Integrators, rootfinders and optimization solvers inside a model, solved by SciML packages in the generated code.
  • CasADi functions as ODEFunction, NonlinearFunction and OptimizationFunction.

To evaluate a model with CasADi itself, in C or with its solvers, use the CasADi front end and its C code generation instead.

Installation

The package supports Julia 1.12 and 1.13:

pkg> add https://github.com/Orbitology/CasADiCodegen.jl

CasADiNative.jl, a dependency, brings the binaries of CasADi 3.8.2.

Contributing

  • Report bugs on the issue tracker.
  • Run the tests with julia --project=. -e 'using Pkg; Pkg.test()'; one group with Pkg.test(; test_args = ["mx"]). On Julia 1.12, also pass julia_args = ["--check-bounds=auto"] (see Keep bounds checks off in tests).
  • Build this manual with julia --project=docs docs/make.jl after julia --project=docs -e 'using Pkg; Pkg.instantiate()'.
