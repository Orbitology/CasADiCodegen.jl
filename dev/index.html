CasADiCodegen.jl: Julia code generation for CasADi functions

CasADiCodegen.jl turns CasADi functions into plain Julia code. You build a model and its derivatives with CasADi, through its Julia front end CasADiNative.jl, and get Julia functions that run without CasADi. They accept arrays, static arrays, sparse matrices and ForwardDiff.jl dual numbers.

A model can be a CasADi function built in Julia, a file saved by CasADi from Python, MATLAB or C++, generic Julia code traced into CasADi, or equations compiled by CasADiCodegen.Models. The generated code can call Julia functions and SciML solvers, and it can serve as the function of a SciML problem.

To run a model with CasADi itself, in C or with CasADi's solvers, use the CasADi front end and its C code generation instead.

Install from GitHub

The package supports Julia 1.12 and 1.13:

pkg> add https://github.com/Orbitology/CasADiCodegen.jl

The dependency CasADiNative.jl brings the CasADi 3.8.2 binaries.

Start with Getting started; Scope and differences from CasADi lists what the package supports.

Report bugs, run the tests and build this manual

  • Report bugs on the issue tracker.
  • Run the tests with julia --project=. -e 'using Pkg; Pkg.test()', or one group with Pkg.test(; test_args = ["mx"]). On Julia 1.12, also pass julia_args = ["--check-bounds=auto"] (see Keep bounds checks off in tests).
  • Build this manual with julia --project=docs docs/make.jl after julia --project=docs -e 'using Pkg; Pkg.instantiate()'.
