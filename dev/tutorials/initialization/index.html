Initialize differential-algebraic equations

The initial values of a differential-algebraic equation (DAE) must satisfy its algebraic equations. In this tutorial, we give the conditions that we know, such as a position or a velocity, to ODEFunction as the keyword initialization: a CasADi function with the arguments of the right side whose result must vanish at the initial time. Before its first step, the solver computes the whole state from the algebraic equations (the zero rows of the mass matrix) and the conditions; the initial state of the problem is only a guess.

using CasADiCodegen, LinearAlgebra
import SciMLBase
using OrdinaryDiffEqRosenbrock: Rodas5P
using OrdinaryDiffEqTsit5: Tsit5
using NonlinearSolve: LevenbergMarquardt, TrustRegion

Write the pendulum in index-1 form

A pendulum of unit mass on a rod of unit length, with the multiplier $\lambda$, has index 3:

\[x'' = \lambda x, \qquad y'' = \lambda y - g, \qquad 0 = x^2 + y^2 - 1.\]

The problem of a System (see Model physical systems with differential-algebraic equations) makes its ODEFunction without the keyword initialization, so we write the right side by hand, in the index-1 form of dummy derivatives: $y$ and $v_y$ are differential, and $x$, $v_x$ and $\lambda$ are algebraic, fixed by the constraint and its first two time derivatives, which CasADi computes:

y, vy, x, vx, λ = (SX.sym(name) for name in ("y", "vy", "x", "vx", "λ"))
g, x0, y0, vy0, t = (SX.sym(name) for name in ("g", "x0", "y0", "vy0", "t"))
variables, slopes = (x, vx, y, vy), (vx, λ * x, vy, λ * y - g)
ddt(e) = sum(jacobian(e, s) * ds for (s, ds) in zip(variables, slopes))

constraint = x^2 + y^2 - 1
u, p = vcat(y, vy, x, vx, λ), vcat(g, x0, y0, vy0)
rhs = CasadiFunction("pendulum", [u, p, t], [vcat(vy, λ * y - g, constraint, ddt(constraint), ddt(ddt(constraint)))])
mass = Diagonal([1.0, 1.0, 0.0, 0.0, 0.0])

The parameters are the gravity g and the targets x0, y0 and vy0. The Levenberg-Marquardt method solves the initialization: it uses the generated Jacobian, accepts any number of equations and tolerates a singular Jacobian. The guess is in the order (y, vy, x, vx, λ):

initialize = SciMLBase.OverrideInit(; nlsolve = LevenbergMarquardt())
conditions(rows...) = CasadiFunction("conditions", [u, p, t], [vcat(rows...)])

function pendulum(guess, rows...; tspan = (0.0, 1.5), parameters = [1.0, 1.0, 0.0, 0.0])
    f = SciMLBase.ODEFunction(rhs; mass_matrix = mass, initialization = conditions(rows...),
                              specialize = SciMLBase.AutoSpecialize)
    SciMLBase.ODEProblem(f, guess, tspan, parameters; initializealg = initialize, abstol = 1e-8, reltol = 1e-8)
end

Start from a position

We start the pendulum at x = 1, y = 0, with the guess λ = 1:

problem = pendulum([0.0, 0.0, 1.0, 0.0, 1.0], x - x0, y - y0)
solution = SciMLBase.solve(problem, Rodas5P())
solution.retcode, solution.u[1]
(SciMLBase.ReturnCode.Success, [1.7442362159299218e-11, -1.748128729957812e-16, 0.9999999999999242, -1.5721979283524567e-25, 1.9501153562475137e-11])

The constraint and its derivatives, the last three elements of the right side, vanish:

rhs(solution.u[1], problem.p, 0.0)
DM([-1.74813e-16, -1, -1.51656e-13, -3.20538e-25, 4.11758e-12])

The multiplier leaves its guess for 0, the value at rest at the side. Any variable can carry a condition, here λ = 0 or vy = 0 with x = 1:

from_lambda = SciMLBase.solve(pendulum([1.0, 0.0, 1.0, 0.0, 0.0], x - x0, λ), Rodas5P())
from_speed = SciMLBase.solve(pendulum([1.0, 0.0, 1.0, 0.0, 0.0], x - x0, vy - vy0), Rodas5P())
from_lambda.u[1], from_speed.u[1]
([4.924719347969326e-9, -2.956125985071502e-17, 1.0000000000000064, -6.312679774375713e-24, 4.541110340407046e-9], [0.00015763479959156736, -1.3303276022816119e-27, 0.9999999912732104, 1.2181771378891547e-24, 0.00015763479960064197])

The height is of order $10^{-4}$, at a double root of the constraint.

Count the conditions

Five variables and three algebraic equations need two conditions. initialization_problem returns the problem at the guess, a NonlinearProblem when it is square and a NonlinearLeastSquaresProblem otherwise:

under = pendulum([0.0, 0.0, 1.0, 0.0, 1.0], x - x0)
over = pendulum([0.0, 0.0, 1.0, 0.0, 1.0], x - x0, y - y0, vy - vy0)
typeof(CasADiCodegen.initialization_problem(problem)).name.name,
typeof(CasADiCodegen.initialization_problem(under)).name.name,
typeof(CasADiCodegen.initialization_problem(over)).name.name
(:NonlinearProblem, :NonlinearLeastSquaresProblem, :NonlinearLeastSquaresProblem)

An underdetermined system returns a solution near the guess, and an overdetermined one succeeds when its conditions agree:

SciMLBase.solve(under, Rodas5P()).retcode, SciMLBase.solve(over, Rodas5P()).retcode
(SciMLBase.ReturnCode.Success, SciMLBase.ReturnCode.Success)

Contradictory conditions fail; with vy = 2 the constraint needs λ = -4, not 1:

target = [1.0, 1.0, 0.0, 2.0]
failed = SciMLBase.solve(pendulum([0.0, 2.0, 1.0, 0.0, 1.0], x - x0, y - y0, vy - vy0, λ - 1; parameters = target), Rodas5P())
failed.retcode
ReturnCode.InitialFailure = 8

Solve the initialization problem alone

Solved alone, the initialization problem shows the residual of the algebraic equations, then of the conditions; no state satisfies them all:

inconsistent = pendulum([0.0, 2.0, 1.0, 0.0, 1.0], x - x0, y - y0, vy - vy0, λ - 1; parameters = target)
alone = SciMLBase.solve(CasADiCodegen.initialization_problem(inconsistent), LevenbergMarquardt())
alone.retcode, round.(alone.resid; digits = 3)
(SciMLBase.ReturnCode.MaxIters, [-0.01, 0.24, 0.422, -0.102, 0.428, -1.336, -0.834])

Its solution is indexed by name, and any method of NonlinearSolve.jl applies:

square = SciMLBase.solve(CasADiCodegen.initialization_problem(problem), TrustRegion())
square.retcode, square[:λ]
(SciMLBase.ReturnCode.Success, -6.60203623813472e-23)

Change the conditions

A new target is a new parameter value and needs no new code:

moving = pendulum([1.0, 0.0, 1.0, 0.0, 0.0], x - x0, vy - vy0)
moving.ps[:vy0] = -0.1
SciMLBase.solve(moving, Rodas5P())[:vy][1]
-0.09999999999968268

Other conditions need a new conditions function, and only its code is compiled.

Solve for a parameter

In a model where x + y is the parameter total, we give two of the three and compute the third; y is an observed variable:

x, total, x0, y0 = SX.sym("x"), SX.sym("total"), SX.sym("x0"), SX.sym("y0")
q = vcat(total, x0, y0)
sum_model = CasadiFunction("sum_model", [x, q, t], [-x, total - x], ["u", "p", "t"], ["du", "y"])

The keyword solved_parameters names the parameters to solve for, whose values in the problem are guesses. With x = 1 and y = 2:

both = CasadiFunction("both", [x, q, t], [vcat(x - x0, (total - x) - y0)])
f = SciMLBase.ODEFunction(sum_model; initialization = both, solved_parameters = [:total])
solution = SciMLBase.solve(SciMLBase.ODEProblem(f, [0.0], (0.0, 1.0), [0.0, 1.0, 2.0]), Tsit5();
                           initializealg = initialize, abstol = 1e-8, reltol = 1e-8)
solution.ps[:total]
2.999999999885773

Start at a steady state

Conditions on the derivatives initialize an ODE too, here the Lotka-Volterra system at a steady state:

r, s = SX.sym("r"), SX.sym("s")
prey = vcat(r, s)
slope = vcat(1.5r - r * s, -3s + r * s)
lotka = CasadiFunction("lotka", [prey], [slope])
steady = SciMLBase.ODEFunction(lotka; initialization = CasadiFunction("steady", [prey], [slope]))
solution = SciMLBase.solve(SciMLBase.ODEProblem(steady, [2.0, 1.0], (0.0, 10.0)), Tsit5();
                           initializealg = initialize, abstol = 1e-8, reltol = 1e-8)
solution.u[1], solution.u[end]
([2.9999999974918508, 1.4999999987459263], [2.99999998265393, 1.4999999935428758])

The guess selects the steady state $(3, 1.5)$ over the origin.
