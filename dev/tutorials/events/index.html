Simulate a bouncing ball

In this tutorial, we simulate a bouncing ball as a SciML problem with a callback and as a CasADi function that returns the contact times and their derivatives, then put the ball in a box where the number of contacts is not known in advance.

using CasADiCodegen
using OrdinaryDiffEqTsit5: Tsit5
import SciMLBase

Drop a ball on the floor

The state of the ball is its height $x$ and its velocity $v$:

\[\dot{x} = v, \qquad \dot{v} = -g, \qquad g = 9.8.\]

A CasADi function of the state alone gives the right side (see Give a CasADi function to a SciML problem), and the ball starts at rest at the height 1:

s = SX.sym("s", 2)                                        # s = [x, v]
fall = CasadiFunction("fall", [s], [vcat(s[2], SX(-9.8))])
problem = SciMLBase.ODEProblem(SciMLBase.ODEFunction(fall), [1.0, 0.0], (0.0, 5.0))

Apply the bounce with a callback

A bounce is a ContinuousCallback at a root of the height that reverses the velocity:

bounce = SciMLBase.ContinuousCallback((u, t, integ) -> u[1], integ -> (integ.u[2] = -integ.u[2]))
solution = SciMLBase.solve(problem, Tsit5(); callback = bounce, abstol = 1e-10, reltol = 1e-10)
minimum(solution[1, :])
7.561366917714058e-17

The lowest height is zero within the tolerance. The callback saves the state twice at each contact, and we compare these contact times with the exact $t_k = (2k - 1) \sqrt{2 h / g}$ for $h = 1$:

contacts = unique(filter(t -> count(==(t), solution.t) == 2, solution.t))
t_exact = (2 .* (1:6) .- 1) .* sqrt(2 / 9.8)
maximum(abs, contacts - t_exact)
8.171241461241152e-14

These contact times come from a SciML solution, outside any graph that CasADi could differentiate.

Return the contact times from a CasADi function

To differentiate the contact times, we make them outputs of a CasADi function. integrator takes the event function as "zero" and the state after an event as "transition" (see Stop at an event). The integrator is called inside an MX graph, and we ask for six events that do not end the integration:

m = MX.sym("m", 2)
ball = Dict("x" => m, "ode" => vcat(m[2], MX(-9.8)), "zero" => m[1],
            "transition" => vcat(m[1], -m[2]))
bounces = integrator("bounces", Tsit5(), ball; events = 6, terminal = false, direction = -1,
                     abstol = 1e-10, reltol = 1e-10)

With direction = -1, only crossings from positive to negative heights count, and terminal = false continues to the final time after the sixth event. bounces takes the initial state and the two times and returns the final state and the contact times; we add their Jacobian by the initial height h as an output, and pass scalars as vectors of one element:

h, t0, tf = MX.sym("h"), MX.sym("t0"), MX.sym("tf")
sf, te = bounces(vcat(h, MX(0.0)), t0, tf)
contact = CasadiFunction("contact", [h, t0, tf], [sf, te, jacobian(te, h)])
contact_f, contact_f! = build_function(contact; expression = Val{false})
xf, times, dtimes = contact_f([1.0], [0.0], [5.0])
maximum(abs, times - t_exact)
8.881784197001252e-15

CasADi differentiates each contact time by the implicit function theorem, so the derivative has the accuracy of the integration. The exact derivative is $(2k - 1) / \sqrt{2 g h}$:

maximum(abs, vec(dtimes) - (2 .* (1:6) .- 1) ./ sqrt(2 * 9.8 * 1.0))
2.886579864025407e-15

Bounce between two walls

The second ball moves in a plane between a floor at $x = 0$ and walls at $y = \pm 1.5$, with a small drag:

\[\dot{x} = v_x, \qquad \dot{y} = v_y, \qquad \dot{v}_x = -9.8 - 0.1 v_x, \qquad \dot{v}_y = -0.1 v_y.\]

The entry "zero" is a column of three event functions, one per surface, each positive inside the box, and "transition" has one column per event function: the floor reverses $v_x$ and either wall $v_y$:

b = MX.sym("b", 4)                                        # b = [x, y, vx, vy]
flip_x = vcat(b[1], b[2], -b[3], b[4])
flip_y = vcat(b[1], b[2], b[3], -b[4])
box = Dict("x" => b, "ode" => vcat(b[3], b[4], -9.8 - 0.1 * b[3], -0.1 * b[4]),
           "zero" => vcat(b[1], b[2] + 1.5, 1.5 - b[2]),
           "transition" => hcat(flip_x, flip_y, flip_y))

With the default exact = true, a call throws when fewer than events events occur; with exact = false, events is an upper bound and the function also returns the number ne of events. With several event functions, it returns the index ie of the event function of each event. We allow 20 events:

walls = integrator("walls", Tsit5(), box; events = 20, exact = false, terminal = false,
                   direction = -1, abstol = 1e-10, reltol = 1e-10)
b0 = MX.sym("b0", 4)
inbox = CasadiFunction("inbox", [b0, t0, tf], [walls(b0, t0, tf)...])
w, w! = build_function(inbox; expression = Val{false})
bf, tw, iw, nw = w([1.0, 0.0, 0.0, 2.0], [0.0], [10.0])
n = Int(nw[1])
17

The ball touches a surface 17 times. The first n entries of iw give the surface of each contact, 1 for the floor and 2 or 3 for a wall, and the remaining entries hold 0:

Int.(iw[1:n])'
1×17 adjoint(::Vector{Int64}) with eltype Int64:
 1  3  1  1  2  1  1  1  3  1  1  1  2  1  1  1  1

Since ne adapts to the final time, the same function gives the path on a grid of final times:

path = [w([1.0, 0.0, 0.0, 2.0], [0.0], [t])[1] for t in range(0, 10; length = 201)]
minimum(p[1] for p in path), extrema(p[2] for p in path)
(0.0014963467399007745, (-1.498329959221639, 1.4999546343460854))

The ball stays inside the box. Each call integrates from the initial time again; a VectorContinuousCallback over the three surfaces gives a dense path in one solve.
