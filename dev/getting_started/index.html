Getting started

We write a small model with CasADi, generate Julia functions for it and its Jacobian, and call them with arrays, static arrays and a sparse matrix; we then write the same functions to a file.

Write the model

using CasADiCodegen loads CasADiNative.jl, the Julia front end of CasADi 3.8.2, whose calls follow the CasADi documentation for Python, with these differences:

  • SX, MX, DM, jacobian, gradient, hessian, substitute, nlpsol and the Opti functions Opti, variable, parameter, minimize, subject_to, bounded, set_initial, solve and value are exported. Every other function, such as set_value and sumsqr, is in CasADiCodegen.C.
  • CasadiFunction makes a CasADi function, since Function is a Julia type.
  • Operations have their Julia meaning: * is the matrix product, sin.(x) and x .^ 2 act on each element, and [a; b] concatenates.
  • Indices start at 1, except in CasADi methods that take the index of an input or output.
using CasADiCodegen

x = SX.sym("x", 3)
y = [sin(x[1]) * x[2]; x[3]^2 / (1 + x[1]^2)]
f = CasadiFunction("f", [x], [y, jacobian(y, x)])

f has one input, x, and two outputs: y and its 2 by 3 Jacobian.

Generate functions for this session

build_function returns an out-of-place and an in-place function:

g, g! = build_function(f; expression = Val{false})
value, J = g([0.3, 1.7, -0.4])
J
2×3 Matrix{Float64}:
  1.62407    0.29552   0.0
 -0.0808013  0.0      -0.733945

An output with one column comes back as a Vector, any other as a Matrix (vector_columns = false keeps the matrix shape). The in-place function takes a tuple of outputs and a tuple of inputs:

out = (zeros(2), zeros(2, 3))
g!(out, ([0.3, 1.7, -0.4],))
out[1]
2-element Vector{Float64}:
 0.5023843513242772
 0.14678899082568808

Avoid allocation with static arrays

With a static array as input, the out-of-place function returns static arrays and does not allocate:

using StaticArrays

value, J = g(SVector(0.3, 1.7, -0.4))
typeof(J)
SMatrix{2, 3, Float64, 6} (alias for StaticArraysCore.SArray{Tuple{2, 3}, Float64, 2, 6})

force_SA = true returns static arrays for any input. Static arrays hold at most 1024 elements over all outputs of one function, such as the Jacobian of 32 states. Above that limit, the function returns ordinary arrays with a warning, and an explicit request for static arrays throws an ArgumentError: force_SA = true here, or inplace = false in a SciML constructor, which applies the limit to each generated array.

Fill a sparse Jacobian

The in-place function also fills a SparseMatrixCSC with the sparsity pattern of the output, and rejects one with another pattern:

using SparseArrays

Js = SparseMatrixCSC(CasADiCodegen.C.sparsity_out(f, 1))   # pattern of the second output: CasADi counts from 0
g!((zeros(2), Js), ([0.3, 1.7, -0.4],))
Js
2×3 SparseArrays.SparseMatrixCSC{Float64, Int64} with 4 stored entries:
  1.62407    0.29552    ⋅ 
 -0.0808013   ⋅       -0.733945

Write the code to a file

generate_julia writes the functions to a module that runs without CasADiCodegen.jl:

path = joinpath(mktempdir(), "f.jl")
generate_julia(f, path; module_name = :F)
include(path)
F.f([0.3, 1.7, -0.4])[1]
2-element Vector{Float64}:
 0.5023843513242772
 0.14678899082568808
F.f!(out, ([0.3, 1.7, -0.4],))
out[2]
2×3 Matrix{Float64}:
  1.62407    0.29552   0.0
 -0.0808013  0.0      -0.733945

The module also holds F.f_nonzeros! (see Choose a form) and these constants:

ConstantContent
NAME, NAMES_IN, NAMES_OUTNames of the function, its inputs and outputs
NNZ_IN, NNZ_OUTNumbers of structural nonzeros of inputs and outputs
NWORKLength of the work vector
SPARSITY_IN, SPARSITY_OUTPatterns (nrow, ncol, colptr, rowval), indices from 1
DEPENDENCIESPackages that the module imports

Each package of DEPENDENCIES must be in the environment that loads the file:

F.DEPENDENCIES
(:NaNMath, :SparseArrays, :StaticArraysCore)

A model with an integrator, a rootfinder or a solver also needs CasADiCodegen.jl, SciMLBase.jl and the package of the algorithm.

Choose a form

CallResultNeeds CasADiCodegen.jl to run
build_function(f)An Expr, for eval or a macroYes
build_function(f; expression = Val{false})Compiled functionsYes
build_function(f; expression = Val{false}, cache = true)The same, cached for later sessionsYes
generate_julia(f, path)A module in a fileNo, unless the model holds a SciML solver

nonzeros = true gives one function (res, arg) -> res on the structural nonzeros of each input and output, in column-major order, as CasADi evaluates it; generate_julia writes it as <name>_nonzeros!.
